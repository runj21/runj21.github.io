工程材料及其应用#

第1章 材料的结构与性能#

1.1　金属的晶体结构#

一、为什么要研究晶体结构#

研究金属晶体结构的核心目的是建立"结构-工艺-性能"之间的关联，为材料的选用和加工提供理论依据。

  1. 性能由微观结构决定：金属的力学性能（强度、塑性、硬度）、物理性能（导电性、导热性）和化学性能（耐蚀性）本质上取决于其内部原子的排列方式。
  2. 指导加工工艺：理解晶体结构有助于掌握塑性变形、再结晶、相变等过程的机理，从而优化热处理、轧制、锻造等工艺参数。
  3. 开发新材料：通过调控晶体结构和缺陷，可以设计出具有特定性能的合金材料。

二、晶体、晶格与晶胞的关系#

概念定义说明
晶体原子在三维空间呈周期性规则排列的固体大多数金属在固态下都是晶体
晶格（空间点阵）用假想的几何线条将原子中心连接起来构成的三维空间格架是对晶体中原子排列规律的几何抽象
晶胞能够完整反映晶格特征的最小几何单元通过晶胞在三维方向上的重复堆砌即可得到整个晶格

关系：晶体 → 抽象为晶格 → 取出最小重复单元即为晶胞。晶胞的形状和大小由晶格常数（a、b、c、α、β、γ）来描述。

三种常见的金属晶体结构#

  • 致密度（Atomic Packing Factor, APF）：晶胞中原子体积占晶胞体积的分数，反映原子在晶胞中的堆积紧密程度。
    • APF 越高 → 原子排列越致密 → 晶胞内部间隙空间小 → 不利于容纳间隙固溶原子；但 FCC/HCP 的密排面多、滑移系丰富，塑性和韧性更好。
    • APF 越低 → 晶胞内部空隙较大 → 可容纳更多间隙原子实现固溶强化；同时 BCC 原子间结合力较强，熔点和高温强度通常更高。
  • 配位数（Coordination Number, CN）：晶体中与任一原子最近邻且等距离的原子数目，直接反映金属键的强弱。
    • CN 越大 → 近邻原子越多 → 金属键越强 → 熔点、弹性模量、强度越高。
    • CN 与致密度共同决定晶体的力学性能，但 CN 不能单独决定塑性——HCP 虽然 CN=12，但滑移系少，塑性反而较差。
  • 滑移系：晶体的一部分相对于另一部分沿特定晶面（滑移面）和特定晶向（滑移方向）发生的相对位移，是金属塑性变形的最主要方式。一个滑移面与其上的一个滑移方向共同构成一个滑移系。
    • 滑移面通常是原子排列最密的面（面间距最大，原子间结合力最弱，最容易发生滑移）。
    • 滑移方向通常是原子排列最密的方向（原子间距最短，位错能量最低，最容易移动）。
结构滑移面滑移方向滑移系数量塑性评价
FCC{111}（4 个面）⟨110⟩（每个面 3 个方向）4 × 3 = 12滑移系最多且密排面间距大，塑性最优
BCC{110}（6 个面）⟨111⟩（每个面 2 个方向）6 × 2 = 12（另有 {112}、{123} 等次级滑移面，总计可达 48）滑移系虽多，但临界分切应力大，低温下塑性较差
HCP{0001} （1 个面）⟨11-20⟩（3 个方向）1 × 3 = 3（加上棱柱面、棱锥面等次级系统，总计约 6~12）滑移系少，塑性最差，常需孪生辅助变形

Schmid 定律：τ = σ cosφ cosλ，其中 φ 为滑移面法向与外力的夹角，λ 为滑移方向与外力的夹角，cosφ·cosλ 称为 Schmid 因子。当滑移系上的分切应力 τ 达到临界分切应力 τ_CRSS 时，该滑移系开始启动。

致密度、配位数与滑移系的综合关系：致密度决定了原子堆积的紧密程度和可容纳间隙原子的能力，配位数反映了金属键的强弱从而影响熔点和弹性模量，而滑移系的数量和临界分切应力才是决定塑性优劣的直接因素。

三、金属晶体的特性#

  1. 确定的熔点：晶体有固定熔点，加热时温度保持不变直至全部熔化。
  2. 各向异性：单晶体在不同晶向上原子排列密度不同，导致性能呈现方向性差异。
  3. 规则的几何外形：在理想条件下可自发形成规则的多面体外形。
  4. 长程有序：原子排列在三维空间具有周期性和对称性。
  5. 多晶体的伪各向同性：实际金属材料为多晶体（由大量随机取向的晶粒组成），各向异性相互抵消，宏观上表现为伪各向同性。

四、晶体缺陷⭐（笔试填空：低温变脆→位错运动受阻；高温塑变→扩散和位错攀移）#

实际晶体中总是存在偏离理想周期性排列的区域，称为晶体缺陷。按几何特征分为三类：

缺陷类型维度典型缺陷对性能的影响
点缺陷0维（零维）空位、间隙原子、置换原子引起固溶强化，提高强度、硬度，塑性、韧性下降
线缺陷1维（一维）位错（刃型位错、螺型位错）位错运动是塑性变形的微观机制；位错密度增加→强度升高（加工硬化）
面缺陷2维（二维）晶界、亚晶界、层错、孪晶界细晶强化的理论基础：晶粒越细，晶界越多，强度越高（Hall-Petch公式），同时塑性、韧性也得到改善

1.2　金属材料的性能#

一、工艺性能#

工艺性能是指金属材料在加工制造过程中表现出的对各种加工方法的适应能力，直接影响加工的可行性和经济性。

工艺性能含义影响因素典型应用
铸造性金属熔化后充填铸型并获得优质铸件的能力流动性、收缩性、偏析倾向铸铁、铸铝件的生产
可锻性金属在压力加工（锻造、轧制、挤压）时塑性变形的能力塑性、变形抗力、锻造温度范围自由锻、模锻、热轧
可焊性金属在一定焊接工艺条件下获得优质焊接接头的能力化学成分、淬硬倾向、焊接热影响区组织结构钢、不锈钢焊接
切削加工性金属被切削加工的难易程度硬度、韧性、导热性、加工硬化倾向车削、铣削、钻孔
热处理工艺性金属通过热处理改善组织和性能的适应能力淬透性、回火稳定性、氧化脱碳倾向调质、渗碳、氮化

要点：工艺性能是选材时必须考虑的前提条件——即使某种材料力学性能优异，若工艺性能差（如难以焊接、难以切削），也可能无法实际应用。

二、力学性能⭐（笔试高频考点：零件失效形式、疲劳强度、交变载荷）#

力学性能是金属材料在外力作用下抵抗变形和断裂的能力，是工程选材最核心的依据。

性能指标符号定义意义
弹性模量$E$材料在弹性变形阶段应力与应变的比值反映材料的刚度，由原子间结合力决定，对组织不敏感
屈服强度$\sigma_s$（或 $\sigma_{0.2}$）材料开始发生明显塑性变形时的应力工程设计中许用应力的计算依据
抗拉强度$\sigma_b$拉伸过程中材料所能承受的最大应力反映材料抵抗均匀塑性变形和断裂的能力
断后伸长率$\delta$试样拉断后标距的伸长量与原始标距的百分比反映材料的塑性
断面收缩率$\psi$试样拉断后断口截面积缩减量与原始截面积的百分比反映材料的塑性，比 $\delta$ 更能真实反映局部变形能力
硬度HBS/HRC/HV材料抵抗局部塑性变形（压痕）的能力综合反映强度和塑性，测试方便，应用最广
冲击韧性$\alpha_k$（或 $A_k$）材料在冲击载荷下吸收塑性变形功和断裂功的能力反映材料抵抗冲击断裂的能力，对缺口和温度敏感
疲劳强度$\sigma_{-1}$材料在交变载荷作用下经无限次循环而不发生断裂的最大应力机械零件失效的主要原因之一
应力-应变曲线典型阶段#

$$\text{弹性变形} \xrightarrow{\sigma_s} \text{屈服} \xrightarrow{\sigma_b} \text{强化（均匀塑性变形）} \xrightarrow{\text{颈缩}} \text{断裂}$$

韧性断裂与脆性断裂：

  • 韧性断裂：断前有明显塑性变形（颈缩），断口呈纤维状，呈暗灰色。
  • 脆性断裂：几乎无塑性变形，断口平齐光亮，呈结晶状或放射状花纹，危害性极大。

第2章　金属材料组织与性能的控制#

2.1　纯金属的结晶#

一、纯金属结晶的条件与过程#

1. 结晶条件#

结晶是指金属从液态转变为固态晶体的过程，必须同时满足热力学条件和动力学条件。

热力学条件：过冷

  • 金属的实际结晶温度 $T_n$ 低于其理论结晶温度（熔点）$T_m$，这一现象称为过冷。
  • 过冷度：$\Delta T = T_m - T_n$，过冷是结晶的必要条件——只有存在足够的过冷度，液态金属中才能形成稳定的固态晶核。
  • 过冷度的影响因素：
    • 冷却速度越快 → 过冷度越大 → 结晶温度越低
    • 金属纯度越高 → 过冷度越小（杂质提供非均匀形核位点）

动力学条件：能量起伏与结构起伏

  • 能量起伏：液态金属中各微小区域的原子热运动能量存在瞬时差异，部分高能原子可暂时脱离液态排列形成短程有序的原子团簇。
  • 结构起伏（相起伏）：液态中原子团簇不断产生、长大又消失的动态过程，为晶核的形成提供了结构基础。

总结：过冷提供热力学驱动力（液固两相自由能差 $\Delta G < 0$），能量起伏和结构起伏提供动力学可能性，二者共同决定结晶能否进行。

2. 结晶过程（形核与长大）#

纯金属的结晶过程分为两个基本阶段：形核和长大，两者在整个结晶过程中同时进行。

（1）形核

形核方式机制特点
均匀形核（自发形核）液态金属中依靠结构起伏自发形成晶核需要较大的过冷度；临界晶核半径 $r^* = \dfrac{2\gamma T_m}{\Delta H \cdot \Delta T}$，其中 $\gamma$ 为界面能，$\Delta H$ 为结晶潜热
非均匀形核（非自发形核）依附于液态中已存在的固态杂质或容器壁面形核所需过冷度远小于均匀形核；实际金属结晶以非均匀形核为主
  • 临界形核功：$\Delta G^* = \dfrac{16\pi\gamma^3}{3(\Delta G_V)^2}$（均匀形核），非均匀形核时因界面能降低，$\Delta G^*$ 大幅减小。
  • 形核率 $N$：单位时间、单位体积液态中形成晶核的数目。形核率随过冷度增大先升高后降低（过大过冷度下原子扩散困难）。

（2）长大

  • 长大方式：以枝晶长大为主要形态——晶核表面的凸起部分因散热条件好而优先生长，形成主轴（一次枝晶），再分出侧枝（二次枝晶），最终形成树枝状晶体。
  • 长大速率 $G$：单位时间内晶体长大的线速度。$G$ 也随过冷度增大先升高后降低。

（3）形核与长大对晶粒大小的影响

$$\text{结晶速率} \propto N \cdot G$$

  • 形核率 $N$ 大、长大速率 $G$ 小 → 晶核多但长得慢 → 晶粒细小 → 力学性能好（强度高、塑性韧性好）
  • 形核率 $N$ 小、长大速率 $G$ 大 → 晶核少但长得快 → 晶粒粗大 → 力学性能差
3. 细化晶粒的方法#
方法原理
增大过冷度提高冷却速度 → $\Delta T$ 增大 → $N$ 增大且 $N/G$ 比值增大 → 晶粒细化
加入形核剂（变质处理）提供大量非均匀形核核心 → 等效增大 $N$ → 晶粒细化（如铸铁中加 Si-Ca，铝中加 Ti-B）
超声波振动、电磁搅拌打碎正在长大的枝晶 → 增加有效晶核数 → 细化晶粒

晶粒度对性能的影响：根据 Hall-Petch 公式 $\sigma_s = \sigma_0 + k \cdot d^{-1/2}$，晶粒越细，强度越高，同时由于变形均匀性提高，塑性和韧性也同步改善。因此，细晶强化是唯一能同时提高强度和塑性的强化方式。

二、纯铁#

某些金属在固态下随温度变化会发生晶体结构的改变，这种现象称为同素异构转变（也称多晶型转变）。铁是最典型的同素异构金属，这一特性是钢能够进行热处理的根本原因。

2.2　合金的结晶#

一、二元合金的结晶过程（四大反应）#

二元合金在结晶过程中，除了液态→固态的基本转变外，还会在特定温度和成分下发生特定类型的相变反应,可归纳为四大基本反应：

反应反应式母相产物特点
共晶$L \rightarrow \alpha + \beta$液相两种固相恒温反应，产物细密，铸造性好
共析$\gamma \rightarrow \alpha + \beta$一个固相两种固相恒温反应，产物更细密（珠光体）
包晶$L + \alpha \rightarrow \beta$液相 + 一个固相一个新固相反应不易完全，易偏析
包析$\alpha + \gamma \rightarrow \beta$两个固相一个新固相固态反应，更难完全

2. 合金性能随成分变化的一般规律#
  • 形成单相固溶体时：强度、硬度呈上凸曲线变化（先升后降，峰值出现在中间成分附近），塑性呈下凹曲线变化。
  • 形成机械混合物时：强度和硬度近似呈直线或略上凸变化（两相简单叠加），在共晶/共析点处因组织最细密而强度最高。
  • 含金属间化合物时：在化合物成分处出现硬度尖峰。
3. 铸造性能与相图#
  • 共晶成分合金：熔点最低，流动性最好，铸造性能最优。
  • 固溶体合金：结晶温度范围（液相线与固相线的温度差）越大 → 流动性越差、偏析倾向越大、缩松越严重 → 铸造性能越差。

2.3　金属的塑性加工#

一、金属的塑性变形#

1. 塑性变形的微观机制#
变形方式机制适用条件
滑移位错沿滑移面和滑移方向运动，使晶体的一部分相对于另一部分发生相对位移主要变形方式，大多数金属在常温下的塑性变形以滑移为主
孪生晶体的一部分沿一定的晶面（孪晶面）和晶向发生均匀切变，变形区域与未变形区域呈镜面对称常作为滑移的补充，在滑移系少的 HCP 金属（如 Mg、Zn）或低温变形时尤为重要

滑移与孪生的对比：

  • 滑移：位错逐步移动，变形量大，晶体取向不变，表面形成滑移线/滑移带。
  • 孪生：大量原子同时位移，变形量小，晶体取向改变 180°（或特定角度），表面出现浮凸。
2. 塑性变形对组织和性能的影响#

（1）微观组织变化

  • 晶粒变形：晶粒沿变形方向被拉长，由等轴状变为纤维状（纤维组织）。
  • 亚结构细化：位错密度急剧增加（从 $\sim 10^6$ 增至 $10^{11}$~$10^{12}$ cm⁻²），位错缠结形成胞状亚结构（亚晶），晶格严重畸变。
  • 织构形成：多晶体中各晶粒的某些晶向趋于一致，形成择优取向（形变织构），导致材料出现方向性（类似单晶的各向异性）。

（2）力学性能变化

  • 加工硬化（应变硬化/冷作硬化）：随着塑性变形程度增加，金属的强度和硬度显著升高，塑性和韧性明显下降。
    • 原因：位错密度增加 → 位错间相互缠结和交割 → 位错运动阻力增大 → 变形抗力升高。
    • 工程意义：是金属强化的重要手段之一（冷拔钢丝、冷轧钢板等），但也使后续加工困难，需要退火软化。
    • 冷作硬化的本质：金属在再结晶温度以下进行塑性变形时，晶格畸变和位错密度急剧增加，导致材料抵抗进一步变形的能力（即强度和硬度）升高，而塑性和韧性下降的现象。冷作硬化可通过再结晶退火消除。
    • 冷作硬化的应用：冷冲压、冷拔、冷轧等冷加工工艺中利用加工硬化提高零件强度；弹簧钢丝的冷拔强化；不锈钢的冷轧强化等。
    • 冷作硬化的消除：通过再结晶退火（加热到再结晶温度以上保温后缓冷），使变形晶粒重新形核并长大为无畸变的等轴新晶粒，加工硬化完全消除，塑性和韧性恢复。
  • 残余内应力：塑性变形不均匀导致晶粒间和晶粒内部产生残余应力，可能引起零件变形或应力腐蚀开裂。

二、塑性变形后加热#

冷变形金属在加热过程中会依次发生以下三个阶段，组织和性能逐渐恢复：

1. 回复（Recovery）#
  • 温度范围：较低温度（纯金属约 $T \leq 0.2 \sim 0.3 , T_m$，$T_m$ 为熔点的绝对温度）。
  • 组织变化：空位扩散、位错重新排列形成亚晶界，晶格畸变部分消除，亚晶略有长大。
  • 性能变化：
    • 残余内应力显著降低。
    • 强度和硬度略有下降，塑性略有升高。
    • 电阻率下降。
  • 工程应用：去应力退火——消除冷加工或焊接后的残余应力，避免变形和开裂，但保留加工硬化效果。
2. 再结晶（Recrystallization）#
  • 温度范围：$T \geq T_{再}$，纯金属的再结晶温度 $T_{再} \approx 0.35 \sim 0.4 , T_m$（K）。
  • 组织变化：变形组织中重新形核并长大出无畸变的等轴新晶粒，逐步取代原来的变形纤维组织，完成"组织重建"。
  • 性能变化：
    • 加工硬化完全消除——强度和硬度恢复到冷变形前的水平，塑性和韧性恢复。
    • 晶格畸变消除。
  • 影响再结晶温度的因素：
    • 变形程度越大 → 再结晶温度越低（储能越多，形核驱动力越大）
    • 原始晶粒越细 → 再结晶温度越低
    • 微量溶质原子（杂质） → 阻碍晶界迁移 → 再结晶温度升高
    • 第二相粒子 → 钉扎晶界 → 阻碍再结晶
  • 工程应用：再结晶退火——消除加工硬化，恢复塑性，使金属可以继续进行冷加工（如多道次拉拔、多道次轧制之间的中间退火）。
3. 晶粒长大（Grain Growth）#
  • 温度范围：在再结晶完成后，若继续升高温度或延长保温时间，晶粒会自发长大。
  • 驱动力：晶界能的降低（大晶粒吞并小晶粒，总晶界面积减小）。
  • 影响：晶粒粗化 → 强度下降，塑性韧性变差，应当避免。
  • 控制措施：严格控制退火温度和保温时间。

再结晶后晶粒大小的影响因素：

  • 加热温度越高、保温时间越长 → 晶粒越粗大
  • 变形程度越大 → 再结晶后晶粒越细（但存在"临界变形度"附近晶粒异常长大的问题，如碳钢约 5%~10% 变形量时）

三、热加工与冷加工#

1. 判定标准#

以再结晶温度为分界线：

加工方式定义特点
冷加工在再结晶温度以下进行的塑性变形产生加工硬化，强度升高、塑性下降；尺寸精度高，表面质量好
热加工在再结晶温度以上进行的塑性变形变形的同时发生再结晶，加工硬化被动态回复/再结晶消除；变形抗力小，塑性好，但尺寸精度和表面质量较差

注意：冷、热加工的分界温度并非固定的，而是取决于该金属的再结晶温度。例如铅的再结晶温度低于室温，故铅在室温下的塑性变形属于热加工；而钨的再结晶温度约 1200°C，故钨在 800°C 下的变形仍属于冷加工。

2. 热加工对组织和性能的影响#

（1）有利影响

  • 消除铸造缺陷：打碎铸态组织中的气孔、缩松、粗大枝晶，使组织致密。
  • 细化晶粒：动态再结晶使晶粒细化，力学性能改善。
  • 形成流线（纤维组织）：铸态组织中的夹杂物（如硫化物、氧化物）沿变形方向被拉长形成流线。

（2）不利影响与注意事项

  • 流线的方向性：流线使材料的力学性能出现方向性——沿流线方向的强度和塑性优于垂直流线方向。工程中应使零件的主应力方向与流线方向一致。
  • 带状组织：铁素体和珠光体交替分布形成带状组织，造成各向异性，需通过正火消除。
  • 过热与过烧：
    • 过热：加热温度过高导致奥氏体晶粒粗大 → 冷却后组织粗化 → 力学性能下降。可通过正火或退火补救。
    • 过烧：加热温度接近固相线，晶界发生氧化或熔化 → 材料变脆，无法挽救，只能报废。
  • 氧化与脱碳：高温下表面形成氧化皮（质量损失）和碳损失（表层硬度降低），影响表面质量。
3. 冷加工与热加工的综合对比#

2.4　钢的热处理⭐⭐⭐⭐⭐#

热处理是将钢在固态下通过加热→保温→冷却三个步骤，改变其内部组织结构，从而获得所需性能的工艺方法。热处理的基本类型包括：加热转变（奥氏体化）、冷却转变（珠光体/贝氏体/马氏体转变）、普通热处理（退火、正火、淬火、回火）、表面热处理和化学热处理。

一、普通热处理#

1. 退火（Annealing）#

将钢加热到适当温度，保温一定时间后随炉缓慢冷却，以获得接近平衡组织的热处理工艺。

退火类型工艺参数目的与适用场合
完全退火加热到 $A_3$ + 30~50°C，缓冷细化晶粒，降低硬度，适用于中碳钢 ，适合切削加工
球化退火加热到 $A_1$ + 30~50°C，缓冷使渗碳体球化，降低硬度，适用于高碳钢 ，适合切削加工
均匀化退火/扩散退火加热到 $A_3$ + 150~250°C，长时间保温后缓冷消除枝晶偏析和成分不均匀，适用于铸锭或铸件
去应力退火加热到 $A_1$ 以下，缓冷消除铸造、焊接、冷加工后的残余内应力，不改变组织
2. 正火（Normalizing）#

将钢加热到 $A_3$（亚共析钢）或 $A_{cm}$（过共析钢）+ 30~50°C，保温后在空气中冷却。

  • 与退火的区别：冷却速度比退火快 → 过冷度大 → 珠光体层间距更小（索氏体），硬度和强度更高。
  • 应用：
    • 作为最终热处理：中碳钢的最终热处理
    • 作为预备热处理：高碳钢便于球化退火，消除锻造、铸造后的组织缺陷，为后续淬火做准备。
    • 改善低碳钢的切削加工性
3. 淬火（Quenching）#

将钢加热到 $A_3$ 或 $A_1$ 以上，保温后以大于临界冷却速度的速度快速冷却，获得马氏体组织的工艺。

（1）淬火温度的选择

钢种淬火温度说明
亚共析钢$A_3$ + 30~50°C获得均匀细小的奥氏体，淬火后得到细马氏体
过共析钢$A_1$ + 30~50°C不完全淬火——保留未溶渗碳体颗粒，既提高耐磨性，又细化马氏体，降低含碳量改善韧性

过共析钢为什么不能加热到 $A_{cm}$ 以上？ ①奥氏体晶粒粗大→马氏体粗大→脆性大；②含碳量过高→$M_s$降低→残余奥氏体增多→硬度反而下降；③氧化脱碳严重。

（2）冷却介质

介质冷却能力适用场合
盐水冷却能力更强碳钢淬火，表面光洁，更容易变形开裂
水冷却能力最强碳钢淬火，表面有软点，容易变形开裂
油冷却能力较弱合金钢淬火，不容易变形开裂

（3）淬透性与淬硬性

概念定义影响因素测定方法
淬透性淬火时获得马氏体层深度的能力主要取决于合金元素含量（除了Co以外，其他提升）端淬试验
淬硬性淬火后能达到的最高硬度主要取决于含碳量直接测量淬火硬度

淬透性好 ≠ 淬硬性高：例如低碳合金钢（如 20CrMnTi）淬透性好（合金元素使 C 曲线右移），但淬硬性不高（含碳量低）。而高碳钢（如 T10）淬硬性高，但淬透性不一定好。

（4）淬火方法

淬火方法工艺特点
单液淬火在一种介质中冷却到底操作简单，但变形和开裂倾向大
双液淬火先水后油（先快冷通过 C 曲线鼻尖，后慢冷减少应力）减少变形开裂，但操作较难控制
分级淬火在 $M_s$ 附近的盐浴或碱浴中停留，使表面与心部温度均匀后再空冷变形小，适用于截面较小、形状复杂的零件
等温淬火在贝氏体转变温度（下贝氏体区）等温保持，获得下贝氏体组织综合性能优异（高强度 + 良好韧性），变形极小，适用于要求高强韧性的零件
4. 回火（Tempering）#

将淬火后的钢加热到 $A_1$ 以下某一温度，保温后以适当方式冷却，以消除内应力、调整组织和性能的工艺。回火是淬火的必然后续工序。

回火类型温度范围组织变化性能变化应用举例
低温回火150~250°C回火马氏体（碳的过饱和固溶体 + 极细ε碳化物）保持高硬度（HRC 58~64），内应力部分消除刃具、量具、滚动轴承、渗碳件
中温回火350~500°C回火托氏体（铁素体 + 极细粒状渗碳体）高弹性极限和屈服强度，一定的韧性（HRC 35~50）弹簧、热锻模
高温回火500~650°C回火索氏体（铁素体 + 粒状渗碳体）综合力学性能优良（强度、塑性、韧性良好匹配）轴、齿轮、连杆等重要结构件

调质处理：淬火 + 高温回火的复合热处理工艺，获得回火索氏体组织，综合力学性能最优，是重要机械零件最常用的热处理方式。

二、表面热处理#

仅改变钢的表层组织（不改变化学成分），使表层获得高硬度、高耐磨性，而心部仍保持良好的塑性和韧性的热处理方法。

1.感应加热表面淬火#
  • 原理：利用电磁感应在工件表层产生涡流，使表层快速加热到奥氏体化温度，随即喷水冷却淬火。
  • 分类：按频率分为高频（100500kHz，硬化层 0.52mm）、中频（110kHz，硬化层 36mm）、工频（50Hz，硬化层 >10mm）。
  • 特点：
    • 加热速度快、时间短，表层奥氏体晶粒细小。
    • 仅表层淬火，心部不受影响。
    • 生产效率高，易于自动化。
  • 应用：齿轮、曲轴、凸轮轴等表面需要耐磨的零件。
2.火焰加热表面淬火#
  • 原理：用氧-乙炔（或其他燃气）火焰直接加热工件表面，随即喷水冷却。
  • 特点：设备简单、灵活，但加热温度不易精确控制，表面质量不如感应加热。
  • 应用：大型零件或单件小批量生产（如大型齿轮、导轨等）。

三、化学热处理#

将钢放入含有某种化学元素的介质中加热保温，使该元素的原子渗入钢的表面，改变表层化学成分和组织，从而获得表层特殊性能的热处理方法。

1. 渗碳（Carburizing）#
  • 原理：将低碳钢（含碳 0.1%0.25%）放入富碳介质中，在 900950°C 加热保温，碳原子渗入表层。
  • 目的：表层含碳量升高至 0.8%1.1%，经淬火+低温回火后获得高硬度、高耐磨性的表层（HRC 5864），心部保持低碳钢的良好塑性和韧性。
  • 渗碳后的热处理：
    • 直接淬火：渗碳后直接淬火，工艺简单但晶粒较粗。
    • 一次淬火：渗碳缓冷后重新加热淬火，晶粒细化。
    • 二次淬火：先在 $A_3$ 以上细化心部晶粒，再在 $A_1$ 以上细化表层晶粒，性能最优但成本高。
  • 应用：齿轮、凸轮轴、活塞销等表面承受摩擦和接触疲劳的零件。
2. 渗氮（Nitriding）#
  • 原理：将钢（通常含有 Al、Cr、Mo、V 等氮化物形成元素）放入含氮介质（如氨气）中，在 500~570°C 加热保温，氮原子渗入表层。
  • 特点：
    • 温度低于渗碳，零件变形极小。
    • 表层形成硬度极高的氮化物（如 AlN、CrN），硬度可达 HV 900~1200，高于渗碳件。
    • 渗氮层薄（通常 0.1~0.6mm），不需要后续淬火。
    • 耐蚀性好（表层致密的氮化物层）。
  • 缺点：处理时间长（数十小时），成本高。
  • 应用：精密齿轮、丝杠、量具、发动机气缸套等要求高精度、高耐磨的零件。
3. 碳氮共渗（Carbonitriding）#
  • 原理：同时渗碳和渗氮，在 820~870°C 加热保温，碳和氮同时渗入表层。
  • 特点：兼有渗碳和渗氮的优点，处理温度比渗碳低、时间更短，表层耐磨性和疲劳强度优于单独渗碳。
  • 应用：中、小型齿轮和轴类零件。

2.5　钢的合金化⭐（笔试多选：弹簧材料描述正确选项、合金元素作用）#

一、合金化的目的#

在碳钢中加入一种或多种合金元素（如 Cr、Ni、Mo、Mn、Si、V、Ti、W 等），可以显著改善钢的性能，主要目的包括：

  1. 提高淬透性：使 C 曲线右移，降低临界冷却速度，用较慢的冷却介质（油冷）即可获得马氏体，减少变形开裂。
  2. 提高强度：通过固溶强化、第二相强化（碳化物、氮化物）、细晶强化等多种机制综合提高强度。
  3. 改善韧性：细化晶粒、提高回火稳定性，使回火后的综合力学性能优于碳钢。
  4. 获得特殊性能：耐蚀（Cr）、耐热（Cr、Mo、W）、耐磨（Mn）、抗高温氧化等。

二、合金元素在钢中的存在形式#

形成非碳化物形成氧化物、氮化物、硫化物等夹杂Al、Ti、N 形成 AlN、TiN（细化晶粒）；S、O 形成夹杂（有害）

四、合金元素对钢的热处理的影响#

1. 对奥氏体化的影响#
  • 大多数合金元素（除 Ni、Co 外）减慢碳的扩散速度 → 奥氏体化和均匀化过程变慢 → 需要更高的加热温度或更长的保温时间。
  • 强碳化物形成元素（V、Ti、Nb、W）形成的稳定碳化物难以溶入奥氏体 → 有效阻止奥氏体晶粒长大（细晶强化），但同时也降低了奥氏体中的碳含量和合金元素含量。
2. 对过冷奥氏体转变的影响（对 C 曲线的影响）#
影响说明
C 曲线右移除 Co 外，几乎所有合金元素（Cr、Mo、Ni、Mn、W、V 等）都延长珠光体和贝氏体转变的孕育期 → 提高淬透性
$M_s$ 点降低除 Co、Al 外，大多数合金元素降低 $M_s$ 温度 → 增加残余奥氏体量 → 需要深冷处理或多次回火
C 曲线分离Cr、Mo、W 等元素使珠光体转变和贝氏体转变的两个"鼻尖"分开 → 可以单独获得贝氏体组织（等温淬火更有利）
3. 对回火转变的影响（回火稳定性/红硬性）#
  • 回火抗力提高：合金元素阻碍碳化物的聚集和长大，使回火时马氏体分解和碳化物粗化过程变慢 → 在相同回火温度下，合金钢比碳钢硬度更高 → 可以在更高温度下回火而不丧失硬度（红硬性）。
  • 二次硬化：含有强碳化物形成元素（V、Mo、W、Ti）的钢，在 500~600°C 回火时，析出极细的特殊碳化物（如 $Mo_2C$、$V_4C_3$、$W_2C$），硬度反而升高的现象。
  • 防止第二类回火脆性：添加 0.2%~0.4% Mo（或少量 W）可以有效抑制第二类回火脆性。

2.6　表面技术#

阳极氧化（Anodic Oxidation）⭐⭐⭐（笔试简答题高频考点：原理 + 如何实现多种颜色）#

1. 基本原理#

阳极氧化是将金属（主要是铝及其合金，也适用于镁、钛等）作为阳极置于适当的电解液中，通过外加直流电场使金属表面发生电化学氧化反应，生成一层致密的氧化膜（以铝为例生成 $Al_2O_3$）的工艺。

电化学反应过程：

  • 阳极（金属工件）：$2Al + 3H_2O \rightarrow Al_2O_3 + 6H^+ + 6e^-$（氧化反应，生成氧化膜）
  • 阴极（石墨或铅板）：$2H^+ + 2e^- \rightarrow H_2\uparrow$（还原反应，析出氢气）
  • 同时，氧化膜在电解液中会发生化学溶解：$Al_2O_3 + 6H^+ \rightarrow 2Al^{3+} + 3H_2O$

关键：氧化膜的生长速度（电化学生成）与溶解速度（化学溶解）之间的动态平衡决定了膜层的最终结构——生成速率 > 溶解速率时膜层持续增厚。

氧化膜的结构特征：

  • 阳极氧化膜呈多孔蜂窝状结构：由底部致密的阻挡层（Barrier Layer）和上部多孔的多孔层（Porous Layer）组成。
  • 多孔层由大量垂直于基体表面的六角形柱状微孔组成，孔径约 10~150nm，孔壁为致密的 $Al_2O_3$。
  • 正是这种多孔结构为后续的着色和封孔提供了基础。
2. 实现多种颜色的方法#

阳极氧化膜的多孔结构使其可以吸收各种着色物质，从而实现丰富的色彩。主要有以下几种着色方法：

（1）染料吸附着色（有机着色）

  • 原理：阳极氧化后将工件浸入有机染料溶液中，染料分子通过物理吸附和化学吸附进入氧化膜的微孔中。
  • 工艺：阳极氧化 → 水洗 → 浸入染料液（50~70°C）→ 水洗 → 封孔
  • 特点：
    • 色彩丰富，可实现几乎所有颜色（红、蓝、绿、黑、金等）。
    • 但耐光性、耐候性较无机着色差，长期暴露于紫外线下容易褪色。
    • 适用于装饰性产品（消费电子产品外壳、家具五金等）。

（2）电解着色（二次电解着色）

  • 原理：将阳极氧化后的工件放入含金属盐（如 Sn、Ni、Co、Cu 盐）的溶液中进行交流电解，金属离子在微孔底部还原沉积，沉积的金属纳米粒子通过光的干涉和散射产生颜色。
  • 颜色控制：通过调节沉积时间和电流密度控制金属沉积量，从而改变颜色。沉积量越多 → 颜色越深（青铜色→棕色→黑色）。
  • 特点：
    • 色调以金属色系为主（香槟色、古铜色、青铜色、黑色）。
    • 耐光性和耐候性极优（金属粒子不易褪色），是建筑铝型材的标准着色方法。
    • 可与染料结合使用（电解着色打底 + 染料叠加）获得更丰富的色彩。

（3）整体着色（一步法着色）

  • 原理：在特定的有机酸电解液（如磺基水杨酸）中进行阳极氧化时，有机酸分子同时嵌入氧化膜中，形成有色的金属-有机络合物，实现氧化与着色同步完成。
  • 特点：工艺简化，颜色均匀，但色系较窄（以灰色、青铜色、黑色为主）。

（4）微弧氧化（等离子体电解氧化，PEO）

  • 原理：在铝、镁、钛合金表面施加高于击穿电压的高电压，使氧化膜在等离子体放电条件下生长，形成陶瓷质的致密氧化膜。
  • 特点：膜层硬度极高（HV 1500~2500）、耐磨耐蚀性优异，可通过调节电解液中的金属盐实现多种颜色。
3. 封孔处理#

着色完成后，必须对氧化膜的微孔进行封孔，以固定着色物质并提高膜层的耐蚀性和耐磨性。

封孔方法原理效果
热水封孔$Al_2O_3 + H_2O \rightarrow Al_2O_3 \cdot H_2O$（勃姆石转化，体积膨胀堵孔）最常用，膜层耐蚀性好
蒸汽封孔高温蒸汽加速水合反应效果优于热水封孔，速度快
镍盐/醋酸镍封孔$Ni(OH)_2$ 沉积封堵微孔封孔质量高，常用于染色件
冷封孔（氟化镍溶液）室温下 $NiF_2$ 沉积封孔节能，适用于大规模生产

阳极氧化工艺流程总结：前处理（脱脂→碱洗→酸洗中和）→ 阳极氧化 → 水洗 → 着色（染料/电解/整体）→ 水洗 → 封孔 → 干燥

2. 铸钢的组织与性能#

（1）铸态组织特征

  • 晶粒粗大：铸钢冷却速度较慢，奥氏体晶粒粗大，冷却后形成粗大的铁素体和珠光体。
  • 魏氏组织：在一定冷却速度下，铁素体沿奥氏体晶界和晶内特定晶面呈针状析出，形成魏氏组织，严重降低塑性和韧性。
  • 成分偏析：铸件凝固过程中先结晶与后结晶部分成分不均匀，产生枝晶偏析。
  • 铸造缺陷：铸态组织中常存在气孔、缩松、夹杂等缺陷。

（2）铸钢的力学性能特点

  • 铸态组织粗大 → 强度较低、塑性和韧性差。
  • 与同成分锻钢相比，铸钢的力学性能通常较低。
  • 但铸钢可以制造形状复杂的零件，这是其不可替代的优势。
3. 铸钢的热处理#

铸钢必须经过热处理才能使用，目的是消除铸造缺陷、改善组织、提高性能。

热处理方法工艺目的
扩散退火（均匀化退火）加热到 $A_3$ + 150~250°C，长时间保温后缓冷消除枝晶偏析和成分不均匀
完全退火加热到 $A_3$ + 30~50°C，缓冷细化晶粒、消除魏氏组织、降低硬度、改善切削性
正火加热到 $A_3$ + 30~50°C，空冷细化晶粒，提高强度和硬度（比退火效果更强）
正火 + 回火正火后在 550~650°C 回火消除正火内应力，综合性能最优

铸钢热处理的关键：细化晶粒是铸钢热处理的首要目标。通过完全退火或正火，将铸态粗大晶粒细化为细小等轴晶粒，同时消除魏氏组织，使力学性能显著改善。

铸钢与铸铁的对比：铸钢的含碳量 < 2.11%，铸铁含碳量 > 2.11%。铸钢的强度、塑性和韧性优于铸铁，但铸造性能（流动性、收缩性）不如铸铁。

二、铸铁#

铸铁是含碳量大于 2.11%（一般为 2.5%~4.0%）的铁碳合金，是工业中应用最广泛的铸造材料。

1. 铸铁的分类与特点#

（1）按碳的存在形式分类

（2）铸铁的石墨化过程

铸铁中碳以石墨形式析出的过程称为石墨化。石墨化程度取决于化学成分和冷却速度：

  • 促进石墨化的元素：C、Si、Al、Ni、Cu（含量越高，石墨化越充分）
  • 阻碍石墨化的元素：Cr、Mo、W、V、Mn、S
  • 冷却速度：冷却越慢 → 石墨化越充分 → 碳越容易以石墨形式析出

石墨化对组织的影响：

  • 第一阶段石墨化（共晶转变阶段）：$L \rightarrow \gamma + G$（石墨），温度约 1148°C
  • 第二阶段石墨化（共析转变阶段）：$\gamma \rightarrow \alpha + G$，温度约 727°C
  • 中间阶段石墨化：$\gamma$ 中碳溶解度下降，析出二次石墨

3.4　有色金属及其合金⭐⭐（笔试多选高频考点：哪些属于有色金属、镍钛合金特点）#

有色金属（非铁金属）是指除铁、铬、锰以外的所有金属。工程中常用的有色金属主要有铝、铜、钛、镁、镍等及其合金。

一、铝合金#

铝是地壳中含量最丰富的金属元素，密度低（2.7 g/cm³，约为铁的 1/3），具有良好的导电性、导热性和耐蚀性，是航空航天、交通运输、建筑等领域的重要结构材料。

1. 铝合金的分类#

铝合金按加工方式分为变形铝合金和铸造铝合金两大类。

（1）变形铝合金（可压力加工铝合金）

类别合金系牌号示例特点典型应用
防锈铝（Al-Mg / Al-Mn）Al-Mg、Al-Mn5A05（LF5）、3A21（LF21）耐蚀性好、塑性好、强度较低、不可热处理强化油箱、管道、容器、装饰件
硬铝（Al-Cu-Mg）Al-Cu-Mg2A11（LY11）、2A12（LY12）强度高（$\sigma_b$ 可达 400~500 MPa）、可热处理强化，但耐蚀性较差飞机蒙皮、翼梁、铆钉
超硬铝（Al-Zn-Mg-Cu）Al-Zn-Mg-Cu7A04（LC4）、7075铝合金中强度最高（$\sigma_b$ 可达 500~700 MPa），但耐蚀性和焊接性差飞机大梁、起落架、火箭结构件
锻铝（Al-Mg-Si-Cu）Al-Mg-Si-Cu2A50（LD5）、6061锻造性好、可热处理强化航空锻件、发动机零件

（2）铸造铝合金

类别合金系牌号示例特点典型应用
铝硅合金（硅铝明）Al-SiZL101、ZL102（ZAlSi12）铸造性最好（流动性好、收缩率小）、耐蚀性好发动机气缸体、壳体、泵体
铝铜合金Al-CuZL201、ZL203耐热性好、强度较高，但铸造性较差内燃机活塞、气缸盖
铝镁合金Al-MgZL301耐蚀性最好、密度最低，但铸造性差船舶零件、化工设备
铝锌合金Al-ZnZL401可自然时效强化，铸造性好模型、医疗器械
2. 铝合金的强化方式#
强化方式适用合金机制
加工硬化（冷变形）防锈铝冷变形增加位错密度，提高强度
固溶强化Al-Mg、Al-MnMg、Mn 等溶入 Al 基体产生晶格畸变
时效强化（沉淀强化）硬铝、超硬铝、锻铝淬火后在室温（自然时效）或加热（人工时效）条件下析出弥散细小的第二相粒子

铝合金的时效强化：铝合金的热处理与钢不同——铝合金没有同素异构转变，其强化主要依靠时效强化。工艺过程为：固溶处理（加热到溶解度曲线以上保温，使合金元素充分溶入基体）→ 淬火（快冷获得过饱和固溶体）→ 时效（在室温或加热条件下析出 GP 区和过渡相，使强度显著升高）。

3. 铝合金的牌号表示方法#

变形铝合金（GB/T 16474）：

  • 四位数字体系：1xxx（纯铝）、2xxx（Al-Cu）、3xxx（Al-Mn）、4xxx（Al-Si）、5xxx（Al-Mg）、6xxx（Al-Mg-Si）、7xxx（Al-Zn）
  • 旧牌号：LF（防锈铝）、LY（硬铝）、LC（超硬铝）、LD（锻铝）

铸造铝合金（GB/T 1173）：

  • ZL + 三位数字：ZL1xx（Al-Si）、ZL2xx（Al-Cu）、ZL3xx（Al-Mg）、ZL4xx（Al-Zn）

二、钛合金⭐⭐（笔试高频考点：镍钛合金形状记忆效应、超弹性、医疗器械应用）#

钛的密度为 4.51 g/cm³（约为铁的 60%），比强度高，耐蚀性优异，是航空航天、化工、医疗等领域的重要结构材料。

1. 钛的特性#
  • 同素异构转变：$\alpha$-Ti（HCP，< 882°C）↔ $\beta$-Ti（BCC，> 882°C）
  • 比强度高：钛合金的比强度（强度/密度）在金属材料中最高
  • 耐蚀性优异：在大多数酸、碱、盐溶液中耐蚀性优于不锈钢
  • 生物相容性好：无毒，与人体组织相容性好，广泛用于医疗植入物
  • 导热性差、弹性模量低：切削加工性差
2. 钛合金的分类#

根据退火状态的组织，钛合金分为三类：

类别组织合金元素特点典型牌号
α 钛合金α 相Al、Sn、Si 等 α 稳定元素高温性能好、焊接性好、室温强度较低、不可热处理强化TA5、TA7（Ti-5Al-2.5Sn）
β 钛合金β 相Mo、V、Cr、Mn 等 β 稳定元素强度高、可热处理强化、冷成型性好，但密度较大、高温性能差TB2（Ti-5Mo-5V-8Cr-3Al）
α+β 钛合金α + β 双相同时含 α 和 β 稳定元素综合性能最好，应用最广，可热处理强化TC4（Ti-6Al-4V）——用量最大

前缀含义示例

TBβ 钛合金TB2、TB6
TCα+β 钛合金TC4、TC11
4. 钛合金的热处理#
热处理方法工艺目的
退火加热到 β 转变温度以下，缓冷消除内应力、稳定组织、恢复塑性
固溶 + 时效固溶处理（加热至 α+β 区或 β 区保温后快冷）→ 时效（400~600°C 保温）获得细小的 α 相弥散析出，提高强度

TC4（Ti-6Al-4V）：占钛合金总用量的 50% 以上，是航空航天领域最重要的钛合金。含 6% Al（α 稳定元素，固溶强化）和 4% V（β 稳定元素，改善加工性），经固溶时效后 $\sigma_b$ 可达 1000 MPa 以上，使用温度可达 400°C。

5. 钛合金的典型应用#
应用领域典型零件选用原因

医疗人工关节、骨钉、牙科种植体生物相容性好、无磁性
汽车排气系统、连杆、气门减重、耐热

三、铜合金#

铜的密度为 8.96 g/cm³，具有优良的导电性（仅次于银）、导热性、耐蚀性和良好的加工性能，是电气、电子、机械等领域的重要材料。

1. 铜合金的分类#

铜合金按化学成分分为黄铜、青铜和白铜三大类。

（1）黄铜（Cu-Zn 合金）

以锌为主要合金元素的铜合金。

类别含锌量牌号示例特点典型应用
普通黄铜（二元黄铜）< 39%（单相 α 黄铜）H68、H70塑性好、冷加工性好弹壳、散热器、波导管
普通黄铜39%~45%（α+β 双相黄铜）H62、H59强度较高、可热加工螺母、垫片、水管
特殊黄铜（多元黄铜）加入 Pb、Sn、Al、Si、Mn 等HPb59-1（铅黄铜）、HSn62-1（锡黄铜）改善切削性、耐蚀性、耐磨性齿轮、阀门、船舶零件

黄铜的牌号：H + 数字（铜含量百分数），如 H68 表示含 Cu 68%、Zn 32%。特殊黄铜在 H 后加主加元素符号，如 HPb59-1 表示含 Cu 59%、Pb 1%。

（2）青铜（非 Cu-Zn 的铜合金）

除黄铜和白铜以外的所有铜合金。

类别主要合金元素牌号示例特点典型应用
锡青铜（Cu-Sn）SnQSn6.5-0.1、QSn7-0.2耐磨性好、弹性好、耐蚀性好弹簧、轴承、齿轮
铝青铜（Cu-Al）AlQAl9-4、QAl10-3-1.5强度高、耐磨耐蚀性好、可替代锡青铜齿轮、蜗轮、船舶零件
铍青铜（Cu-Be）BeQBe2、QBe1.7铜合金中强度最高（$\sigma_b$ 可达 1200 MPa）、弹性极限高、无磁性精密弹簧、弹性元件、防爆工具
硅青铜（Cu-Si）SiQSi3-1强度较高、耐蚀性好、铸造性好弹簧、化工设备

青铜的牌号：Q + 主加元素符号 + 数字（主加元素含量百分数），如 QSn6.5-0.1 表示含 Sn 6.5%、P 0.1%。

（3）白铜（Cu-Ni 合金）

以镍为主要合金元素的铜合金。

类别牌号示例特点典型应用
普通白铜B19、B30耐蚀性优异（尤其耐海水腐蚀）、电阻率高船舶零件、电阻丝、热电偶
锌白铜（德银）BZn15-20银白色外观、耐蚀性好装饰品、餐具、乐器
锰白铜BMn3-12（锰铜）电阻率高且稳定精密电阻、应变片

白铜的牌号：B + 数字（镍含量百分数），如 B19 表示含 Ni 19%。

2. 铜合金的强化方式#
强化方式适用合金说明
固溶强化黄铜、白铜Zn、Ni 等溶入 Cu 基体产生晶格畸变
加工硬化所有铜合金冷变形提高强度，但降低塑性
时效强化（沉淀强化）铍青铜、钛青铜固溶 + 时效处理，析出弥散第二相
第二相强化锡青铜、铝青铜硬质第二相（如 δ 相 Cu₃₁Sn₈）提高耐磨性
3. 铜合金的综合对比#
对比项目黄铜青铜白铜

铜合金选用原则：

  • 要求导电性好、成本低的零件 → 纯铜或普通黄铜
  • 要求耐磨性好的零件 → 锡青铜、铝青铜
  • 要求高强度、高弹性的零件 → 铍青铜
  • 要求耐海水腐蚀的零件 → 白铜（Cu-Ni 合金）
